# Plants vs. Zombies
Plants vs. Zombies project is a simulation of the mobile Plants vs. Zombies game. 
We implemented it as our final AP project by using QT framework and in C++ coding language. 
We also have used network programming in our code so that two players can compete in this game. 
The program has two major parts, authentication, and game play ground. When you sign up, your information is saved on the server side of the project with high security. 
Then you can enter and choose a section in  the game menu.

# Menu 
## Start
When you click on start, you will be guided to a waiting page till your opponent also announces that he is ready. After your opponent joins, the game starts. 
The game has two rounds and your roles are randomly chosen by the server in the first round. If in each round duration, at least one zombie can reach the end of the plant field, the zombie has won, otherwise, the plant is the winner. In the game window, you can also communicate with your opponent by sending emojis in the chat box. After each competition, the information about the game will be saved in a file and can be seen by players later on.
## Edit Profile
In this section, the user can edit the information saved in sign-up. 
## Game History
The user can see the history of games he has played including the date and time, opponent user name, roles, and results of each round.
## Exit
close the program

The general steps to run the game:
a. run the server

c. run the project 
d. enter the IP you copied
